| terminology       | explanation |
| ----------------- | ----------- |
| data type         | what type of data is stored in a variable |
| variable          | stores data values |
| assignment        | assigns values to variables |
| dynamically typed | variable types are known during run-time and doesn't require type specification |
| input             | reads user input and returns a string |
| output            | text, files, pictures etc made by a program |
| type casting      | convert data from one type into another |
| boolean           | can only be true or false |
| string            | text |
| f-string          | formatted string, allows writing variables and expressions inside strings using curly brackets { } |
| indentation       | spaces at the start of a code line, used to group code into blocks |
| convention        | style guidelines defining how to write code, for example, how to name things like variables, classes, constants etc |
|                   |             |
